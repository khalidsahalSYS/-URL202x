# -URL202x

تطبيق اجتماعي خفيف لأجهزة Android، مستوحى من بساطة تطبيقات التواصل الخفيفة، مع التركيز على السرعة وتقليل استهلاك البيانات والذاكرة.

## التوافق

يهدف التطبيق إلى دعم Android 5.0 (Lollipop، API 21) حتى Android 16 (API 36).

## تشغيل المشروع

افتح المشروع في Android Studio باستخدام JDK 17، ثم نفّذ مزامنة Gradle وشغّله على جهاز أو محاكي يعمل بنظام Android 5.0 أو أحدث.

## البنية الحالية

- `app/src/main/java/com/url202x/socialapp/MainActivity.kt`: نقطة تشغيل التطبيق والتفاعلات الأولية.
- `app/src/main/res/layout/activity_main.xml`: واجهة عربية أولية تتضمن القصص والمنشورات وشريط التنقل.
- `app/src/main/res/values/`: الألوان والنصوص والأنماط.

## ملاحظات

هذه نسخة أولية للواجهة فقط. تسجيل الدخول الحقيقي، الخادم، رفع الصور، والرسائل غير مفعّلة بعد. التطبيق لا ينتسب إلى Facebook ولا يستخدم علاماته أو خدماته.
