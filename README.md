# URL202x

تطبيق اجتماعي خفيف لأجهزة Android، مستوحى من بساطة تطبيقات التواصل الخفيفة، مع التركيز على السرعة وتجربة استخدام بسيطة ومناسبة للأجهزة القديمة والاتصالات البطيئة.

## ما تم تنفيذه

- واجهة عربية من اليمين إلى اليسار.
- موجز منشورات تجريبي بواجهة بسيطة وخفيفة.
- إنشاء منشور محليًا وإضافته مباشرة إلى أعلى الموجز.
- التفاعل مع المنشورات بزر الإعجاب.
- لا يحتاج التطبيق إلى أذونات أو اتصال بالإنترنت في هذه النسخة.

## التوافق

يستهدف المشروع Android 5.0 (API 21) فما فوق، مع إعداد البناء على Android 16 (API 36). يستهدف التطبيق API 35 لتوافق سلوك الإشعارات والتنقل الحالي.

## البناء والتشغيل

1. افتح المشروع في Android Studio حديث مع تثبيت Android SDK 36.
2. انتظر مزامنة Gradle.
3. شغّل مهمة `:app:assembleDebug` أو اضغط Run لتثبيت التطبيق على جهاز أو محاكي.

يتطلب البناء JDK 17 أو أحدث متوافقًا مع Android Gradle Plugin 8.10.1.
